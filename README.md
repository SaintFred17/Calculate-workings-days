# Расчёт смены

Калькулятор оплаты смены ассистента оператора (1st / 2nd AC): разовые смены и проекты, PDF по смене и сводный PDF за несколько смен.

Открывается по адресу https://saintfred17.github.io/Calculate-workings-days/

Данные хранятся только на устройстве (в браузере). Для резервной копии и переноса между устройствами — кнопки «Экспорт проектов» и «Импорт проектов».
